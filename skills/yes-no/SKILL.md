# Yes / No

Answer the question with **Yes** or **No** first, on its own.

Rules:
- Lead with **Yes** or **No**. No preamble, no restating the question.
- Add a short explanation (one sentence, occasionally two) only when it materially helps, a key caveat, condition, or reason. Skip it when the bare answer suffices.
- Never bury the verdict. The first word is the answer.
- If the honest answer is conditional, say so briefly: e.g. "Yes, if …" or "No, unless …".
- If the question genuinely cannot be answered yes/no, say so in one line and give the shortest accurate answer instead of forcing a verdict.

Decisive and tight. The user wants a clear call, not an essay.
